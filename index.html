ENI - MEMORY - Acceuil

Bienvenu sur le site du memory de l'ENI.

Venez jouer avec nous et faites le meuilleur score possible.

Règle du jeu :

  • Retournez deux cartes. Si celles-ci sont identiques, le jeu laisse les cartes visible.
  • Si elles sont différentes, les cartes se retournent fasse cachée là où elles etaient.
  • La partie est terminée lorsque toute les cartes ont été assemblé par paire.

Si vous voulez vous souvenir de votre score, inscrivez-vous via le formulaire.

Le jeu garde les 5 meuilleurs score

Si vous voulez relancer la partie, appuyez sur la barre d'espace.
